# Headache Diary / Дневник головной боли (Android)

Дневник головной боли и мигрени для Android: время начала приступа записывается одним нажатием, есть виджеты,
календарь, статистика, по желанию погода и давление, данные с часов через Health Connect и PDF-отчёт для врача.
Все данные хранятся только на телефоне.

## Скачать
Готовый APK (Android 8.0 и новее) лежит в [Releases](../../releases/latest). Откройте файл на телефоне и разрешите
установку из этого источника. Приложение подписано ключом автора; контрольная сумма SHA-256 указана в описании релиза.

**English:** a headache and migraine diary for Android 8.0+. Download the APK from
[Releases](../../releases/latest), open it on the phone and allow installing from this source. All data stays on the phone.

Сделано на Kotlin, Jetpack Compose и Room.

## Сборка
1. Установите Android Studio (в комплекте SDK и JDK).
2. File → Open → выберите файл `settings.gradle.kts` в корне проекта, дождитесь Gradle Sync.
3. Подключите телефон (отладка по USB) или создайте эмулятор и нажмите Run ▶.
4. Тесты: `Run → Run 'All Tests'` в `app/src/test` (локальные модульные тесты, телефон не нужен).
5. Релизная сборка с подписью: см. [RELEASE.md](RELEASE.md).

## Возможности
- Кнопка «Болит голова» мгновенно сохраняет текущее время начала приступа; «Боль прошла» закрывает приступ.
- Два виджета: кнопка боли (начало и конец приступа в одно касание) и «Неделя» (7 дней цветом + «Без боли сегодня»).
- Тип: мигрень / обычная головная боль; сила 1–10; симптомы; провокаторы; лекарство и эффект; заметки.
- Календарь месяца с цветом по силе боли, статистика, график силы боли за 30 дней.
- Отметка «день без боли» (на главном экране, в календаре, в вечернем напоминании и виджете «Неделя»).
- Факторы дня (стресс, кофеин, алкоголь, вода, еда) для любого дня; статистика сравнивает дни с болью и без неё.
- Погода и давление (по желанию): температура, давление и его изменение за 3 и 24 часа при каждом приступе;
  сравнение с обычной погодой в том же месте. Источник — Open-Meteo, запасной — MET Norway; наружу уходят
  только координаты, округлённые до ~1 км.
- Прогноз давления на ближайшие сутки на главном экране и утреннее уведомление о перепаде (молчит, если по записям
  перепады почти не предшествуют приступам).
- Данные с часов из Health Connect (по желанию; например Nothing X / CMF Watch): сон перед приступом, шаги за сутки и
  пульс в покое, а также (отдельным переключателем) даты менструаций для проверки «околоменструального окна».
  Только чтение, данные остаются на телефоне.
- Вечернее напоминание «была ли сегодня боль?».
- PDF-отчёт для врача за выбранный период: сводка, график силы боли и давления, список приступов обычным языком.
- Резервная копия в JSON, восстановление (без дублей) и автоматическая ночная копия в выбранную папку.
- Защита приложения отпечатком или кодом экрана блокировки (скрывает содержимое из скриншотов и списка недавних).
- Тема (светлая / тёмная / как в системе), язык: русский, украинский, английский, немецкий, как в системе.

## Иконка
Исходная картинка значка — `design/app-icon.png` (прозрачные углы). Из неё сделана адаптивная иконка: слой рисунка
`res/drawable-*dpi/ic_launcher_foreground.png` (рисунок занимает 85% безопасной зоны, край мягко растворяется в фон)
и фон-градиент `res/drawable/ic_launcher_background.xml`, подобранный по цветам углов картинки. Чтобы заменить
иконку, положите новую картинку и пересоздайте слои (в Android Studio: правый клик на `res` → New → Image Asset).

## Локализация
Строки лежат в `app/src/main/res/values/strings.xml` (English, по умолчанию) и в `values-ru`, `values-uk`, `values-de`.
Чтобы добавить язык: создайте `values-<код>/strings.xml` с теми же ключами, добавьте язык в `AppLanguage`
(`settings/AppSettings.kt`) и чип в `SettingsScreen`.

## Заметки
- Приложение не заменяет консультацию врача; выводы в статистике — лишь подсказки по вашим записям.
- `androidx.health.connect:connect-client` закреплена на `1.1.0-beta01`: более новые версии требуют compileSdk 36 и AGP 8.9.1+.
