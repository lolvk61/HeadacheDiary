# Дневник головной боли (Android)

Kotlin + Jetpack Compose + Room. Данные хранятся только на телефоне.

## Сборка
1. Установите Android Studio (в комплекте SDK и JDK).
2. File → Open → папка `HeadacheDiary`, дождитесь Gradle Sync (скачает нужные компоненты).
3. Подключите телефон (отладка по USB) или создайте эмулятор и нажмите Run ▶.
   Для APK: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Возможности
- Кнопка «Болит голова» мгновенно сохраняет текущее время начала приступа.
- Тип: мигрень / обычная головная боль; сила 1–10; симптомы; провокаторы; лекарство и эффект; заметки.
- «Боль прошла» — фиксирует время окончания и длительность.
- Календарь месяца с цветом по силе боли, статистика за 30/90 дней, экспорт для врача.
