# Headache Diary / Дневник головной боли (Android)

Kotlin + Jetpack Compose + Room. Данные хранятся только на телефоне.

## Сборка
1. Установите Android Studio (в комплекте SDK и JDK).
2. File → Open → выберите файл `settings.gradle.kts` в корне проекта, дождитесь Gradle Sync.
3. Подключите телефон (отладка по USB) или создайте эмулятор и нажмите Run ▶.
   Для APK: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Возможности
- Кнопка «Болит голова» мгновенно сохраняет текущее время начала приступа; «Боль прошла» закрывает приступ.
- Виджет на рабочий стол: запись начала и конца боли в одно касание.
- Тип: мигрень / обычная головная боль; сила 1–10; симптомы; провокаторы; лекарство и эффект; заметки.
- Календарь месяца с цветом по силе боли, статистика, график силы боли за 30 дней.
- Настройки: тема (светлая / тёмная / как в системе), язык (русский / English / как в системе).
- Резервная копия в JSON и восстановление из неё (без дублей).
- PDF-отчёт для врача за выбранный период: краткая сводка и список приступов обычным языком.

## Локализация
Строки лежат в `app/src/main/res/values/strings.xml` (English, по умолчанию) и
`values-ru/strings.xml` (русский). Чтобы добавить язык, создайте `values-<код>/strings.xml`
и добавьте его в `AppLanguage` (`settings/AppSettings.kt`) и в `SettingsScreen`.
