# Релизная сборка

Приложение подписывается вашим личным ключом. **Ключ и пароли нигде, кроме вашего компьютера, хранить не нужно, и в репозиторий
они не попадают** (`*.jks` и `keystore.properties` добавлены в `.gitignore`). Потеряете ключ — не сможете обновлять уже
установленное приложение, поэтому сделайте копию файла ключа в надёжное место.

## 1. Создать ключ (один раз)

Из папки проекта (JDK есть в составе Android Studio, обычно `.../Android Studio/jbr/bin/keytool`):

```
keytool -genkeypair -v -keystore release-key.jks -alias headache-diary -keyalg RSA -keysize 2048 -validity 10000
```

Команда спросит пароль хранилища, пароль ключа и данные владельца (можно оставить пустыми).

## 2. Указать ключ сборке

Скопируйте `keystore.properties.example` в `keystore.properties` и впишите пароли и путь к `release-key.jks`.

## 3. Собрать

- **Android Studio:** Build → Generate Signed App Bundle / APK → APK → выберите `release-key.jks` (или просто
  Build → Build Bundle(s) / APK(s) → Build APK(s) при заполненном `keystore.properties`).
- Готовый файл: `app/build/outputs/apk/release/app-release.apk`. Его можно установить на телефон
  (разрешив установку из этого источника) или передать другому человеку.

## Перед выпуском стоит проверить

- В `app/build.gradle.kts` увеличить `versionCode` (и `versionName`) при каждом новом выпуске.
- `isMinifyEnabled` сейчас выключен (сборка надёжнее, размер не критичен). Если включите сжатие R8, обязательно проверьте
  приложение целиком: виджеты, отчёт, Health Connect и восстановление из копии.
- Приложение читает Health Connect и определяет местоположение: для публикации в магазине понадобится политика
  конфиденциальности (в приложении есть экран с пояснением для Health Connect).
